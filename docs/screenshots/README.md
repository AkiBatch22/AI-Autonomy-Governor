# Screenshot Capture Guide

No product screenshots are currently committed. Add real captures here only after running the application against the synthetic demo dataset; do not use fabricated UI images or production/customer data.

Recommended files:

- `dashboard.png` — AI Employee identity, Safe Autonomy, autonomous accuracy, Human Review rate, execution volume, active Governing Policy, and analytics charts. **Wait until the current root-route/dashboard mismatch is fixed before capturing this.**
- `simulator.png` — proposed thresholds, current-versus-proposed results, Human Review impact, and PASS/FAIL result.
- `recommendations.png` — Governor Recommendation summary plus the Autonomy vs Risk frontier.
- `audit-trail.png` — saved/active/retired policies and linked simulation history.

Capture guidance:

1. Use **Accounts Payable AI** with the seeded synthetic data.
2. Use a consistent desktop viewport, ideally 1440×900 or similar.
3. Avoid browser chrome where possible.
4. Confirm no database URLs, local paths, credentials, or `.env` contents are visible.
5. Compress PNGs without making text unreadable.
6. After adding the files, place their Markdown image links in the root README's Product Screens section.
